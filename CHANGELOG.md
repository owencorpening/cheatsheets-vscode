# Changelog

## 0.2.0

- New shortcut: **Ctrl+Alt+C** (Mac: **Ctrl+Cmd+C**) shows the Cheatsheets panel, or hides the sidebar if it's already showing. The old Ctrl+Shift+C clashed with VS Code's "Open New External Terminal".
- New files, renames, and edits in your cheatsheets folder show up on their own. No more manual Refresh.
- The cheatsheet you're reading stays open when the list refreshes.
- Markdown now uses the full [marked](https://github.com/markedjs/marked) parser: tables, nested lists, task lists, and the rest of GitHub-flavored Markdown render properly.
- Removed the extra "Open Preview to the Side" item that Cheatsheets added to every Markdown file's right-click menu.
- File and folder names are escaped in the panel, and the panel only opens files that are in your cheatsheets folder.
- Marketplace listing: icon, license, README, and this changelog.

## 0.1.0

- First version: Markdown and HTML cheatsheets in the secondary sidebar, with checkboxes that remember their state.
